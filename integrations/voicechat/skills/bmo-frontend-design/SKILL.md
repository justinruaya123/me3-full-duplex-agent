# BMO frontend design

The brief sets the look. Keep an existing site's visual language on revisions. If the user specifies a brand, palette, typography or layout, use it for those choices. Fill unspecified choices from the BMO readable theme.

Start with what someone came to read or do. For a schedule, bring the next event and time into view first. For an article, give the text a comfortable line length. Reserve split panes for content that benefits from comparison. At the 800 × 600 display size, keep the main action visible and let content scroll naturally. Collapse secondary columns on narrow screens.

Use paper for reading surfaces, ink for text and primary for actions or links. Reserve screen and shell accents for grouping and emphasis. Use the UI font stack for reading and the mono stack for code or aligned values. Choose a small set of spacing steps from the theme. Give interactive elements visible keyboard focus and comfortable touch targets. Pair status colors with text. Respect reduced motion.

For private IntelligentUI views, send semantic headings, lists, tables and controls so the host can apply the theme. For exported sites, put needed styles in the bundle and use local font fallbacks. Keep character artwork, private face packs and remotely hosted assets out of the default design.
